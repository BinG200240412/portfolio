# 作品页面滚动规范

所有作品详情使用纵向原生版面吸附，封面和主要内容板块为吸附单位。每个版面至少一屏；内容、图像超过一屏时自然增高，允许继续滚动读完，不固定高度或裁切。

- 公共实现：`assets/page-snap.css`、`assets/page-snap.js`。新作品需要在脚本中登记主要板块，避免把装饰、小标题或每张画廊卡片各自拆成一页。
- 数独：`assets/sudoku-case.css`、`assets/sudoku-scroll.js`，保留盘面随滚动回正、缩小停靠的连续动画。
- 狗GO：`assets/xr-scroll-pages.css`，保留已有桌面与手机分页。
- 集合页和关于我按实际栏数吸附；桌面并排内容作为同一版面，手机纵排可独立吸附。
- 在实际滚动文档上应用 `scroll-snap-type: y mandatory`；作品在首页 iframe 中打开时，由 iframe 内的文档负责。
- 右侧用一列点阵灯珠表示实际吸附版面，灯珠数量随页面数量变化；当前页的灯珠放大并挤开邻近灯珠，点击灯珠可跳转。长版面阅读时保持当前点，不拦截滚轮或触摸滚动。只有存在多个版面时才用灯珠替代原生滚动条。
- 媒体弹窗打开时暂停背景吸附；减少动态模式不强制平滑滚动。不拦截滚轮、不添加滚动计时器。

发布前检查桌面与手机的首屏、下一板块、长内容末尾、弹窗关闭和中英文切换。
