- 新增内容填入原文案区：操控机器狗与地点任务的概念、真实验证范围、合作背景及本人分工。主张、分工、合作背景和小样状态留在封面文字区。

- Unity / Quest 3演示与概念宣传片回到原位置，两者的实际/设想范围在文字中区分；AI游记仍是延展。
