## 一、认识这款数独

### 1. 开场：这是一款什么样的数独？

替换现有「学会推理，分享喜悦。」的标题与导语。

**标题**

这是一款什么样的数独？

**正文**

一款为数独爱好者设计的纯净数独。极简、克制，带一点纸笔的气息。你可以独自推敲，也可以获得分步辅导，记录自己的解题过程，把一道好题分享给朋友。

### 2. 紧接开场：双手机第一印象

这一处先让产品画面说话，不再加一遍「希望它是什么样的软件」的提问。

**字标**

sudoku.

**主标语**

凡事有解。

**短文案**

留一点安静，给下一步思考。

**双手机画面方案**

| 手机 | 选用画面 | 观众首先看到什么 |
| --- | --- | --- |
| 前机，主要画面 | 分步辅导：盘面、高亮范围与「先自己想想」卡片 | 实际解题状态，以及它如何陪人理解一道题 |
| 后机，简洁画面 | 原生启动页：纸白底、九宫格 Logo、sudoku 字标 | 品牌、留白、色彩与轻柔的启动节奏 |

推荐以「辅导 + 品牌启动」替换目前「主棋盘 + 辅导」的相近组合。前机承担功能信息，后机呈现气质。启动画面已有原生实现，独立截图与录屏待后续采集；本轮不替换素材。

### 3. 价值观：凡事有解

**标题**

给人继续推下去的信心。

**正文**

面对一道数独，观察、排除，再往前推一步，原本复杂的局面会慢慢清楚。我想留下的，是这种思考的耐心，以及找到下一步时重新生出的信心。

所以，品牌只留下四个字。简短，有一点余味，也把我相信的力量放在其中。

### 4. 尊重它的来路

**标题**

一道题，也有它的来路。

**正文**

我把数独的介绍与历史放进产品，让人在开始解题之外，也能认识它如何成为今天的样子。理解它的来路，也是理解这款产品为什么重视规则、推理，以及安静思考的乐趣。

**配图方向**

使用 App 内真实的介绍与历史界面；开发者介绍不作为品牌启动页的替代图。

## 二、希望它是什么样？

### 1. 产品取舍

**标题**

极简、克制，也足够完整。

**正文**

我不希望广告与繁复的参数打断一局数独。设计从盘面出发，把经常使用的操作放在手边，让更深入的功能在需要时展开。

它也应当容纳数独爱好者更长久的使用：保留一道未解完的题，回看一次推理，理解卡住的一步，再把这道题分享出去。

### 2. 为谁设计

**标题**

把时间留给题目。

**正文**

我把重点放在独自推理和朋友之间的分享，刻意不以竞速、排名组织体验。简单、中等、困难、专家、世界难题，五档难度供人按自己的节奏选择；需要时，也能进入经典名题，慢慢研究。

### 3. 品牌与字体

**标题**

字形里的纸笔气质。

**正文**

我希望界面像一张经过整理的纸：清楚，有留白，也保留一点书写的温度。字体因此承担不同角色，让题目的条件与自己的思考，在盘面上有清楚的区别。

| 字体 | 页面文案 |
| --- | --- |
| Fraunces · 字标 | 柔和的衬线与有起伏的轮廓，为 sudoku 留下一点书卷气。字距与句点之间保留呼吸。 |
| 源云明体 · 中文 | 用明体的笔画与节奏承接说明，让中文也延续纸面的气质。 |
| EB Garamond · 题目数字 | 给定数字像已经印在纸上的条件，稳定、清楚，便于持续观察。 |
| Mynerve · 填写与候选 | 自己填入的数字带着手写感，候选笔记也沿用这一笔迹。 |

### 4. 外观与颜色

**标题**

让颜色有它的用途。

**正文**

纸白与墨色承载主要信息，低饱和的颜色用来提示选择、进度和观察范围。颜色也可以成为自己的推理记号：把需要对照的格子标出来，让思路在盘面上留下线索。

**配色图注**

鼠尾绿、灰青、雾蓝、土黄、灰玫、砖红，组成预设主题色，也支持自定义主题色。格子标记另有六色，用于辅助个人推理。

### 5. 动效与触感

**标题**

让动作接得上思路。

**正文**

启动时，九宫格 Logo 以轻微的明暗与缩放形成光波；开始一局，盘面逐格铺开；唤出辅导时，视觉与触感一起回应操作。动效帮助人理解状态如何变化，也给思考留出自然的节奏。

### 6. 融入 iOS 的组件

**标题**

熟悉的操作，自己的气质。

**正文**

暂停、更多操作、次级页面与底部导航，尽量沿用 iOS 的组件和交互习惯。盘面、进度回溯、标色操作与辅导卡则围绕数独本身设计，在熟悉的系统体验里保留产品的特点。

| 组件或形态 | 页面文案 |
| --- | --- |
| Liquid Glass 按钮 | 暂停与更多操作在 iOS 26 使用系统玻璃材质，轻轻浮在盘面之外。 |
| 连续圆角 · RoundedRectangle | 盘面与数字键用连续圆角收住边界，让规则的网格也有柔和的外形。 |
| Sheet · 分层弹出界面 | 设置、残局选择、分享等次级内容使用系统弹层，保留与当前对局的联系。 |
| TabView · 底部导航 | 记录、残局、教程与设置沿用系统标签导航，入口保持熟悉、清楚。 |
| 自定义进度条 | 一条可回溯的落子轨迹，同时承担恢复进度与长按唤出辅导的入口。 |
| 自定义辅导卡 | 解释与盘面高亮联动，让观察范围和当前提示一起呈现。 |

### 7. 辅导的设计立场

**标题**

在答案之前，留一次自己判断的机会。

**正文**

我希望把 AI 用在解释线索、引导观察上。辅导从当前盘面出发，逐步缩小观察范围，解释为什么可以这样推，再由玩家自己完成填写。每一次帮助，都应该让下一次独立解题更有把握。

## 三、它如何被使用

以实际操作过程为主：动作发生，界面稳定，再展开周围的组件分析。下面是各组演示需要表达的内容，不额外增加重复导语。

### 1. 开始一局与主盘面

**标题：从一格开始。**

盘面逐格铺开，计时与进度进入各自的位置。选中空格，填入数字或留下候选笔记，推理就从这里开始。

| 标注 | 文案 |
| --- | --- |
| 进度条 | 记录落子进度；拖动可回看并恢复到已经走过的位置。 |
| 暂停 | 暂时离开这一局，让计时与盘面一同停下。 |
| 计时 | 看见这一局花了多久，按自己的节奏继续。 |
| 难度 | 在五档难度之间选择适合自己的题目。 |
| 题目出处 | 保留题目来源与评级，方便认识和查找这道题。 |
| 九宫格盘面 | 用层级、高亮与字形区分条件、选择和自己的填写。 |
| 解题工具 | 把撤销、候选笔记等常用操作放在盘面附近。 |
| 数字键盘 | 选定格子后填写数字，或切换为候选记录。 |

### 2. 填写、笔记与回溯

**标题：落子可以撤回，思路可以继续。**

确定时填入数字，尚未确定时记下候选。需要重新检查，就撤销一步，或沿进度条回到先前的状态，重新看一遍自己的判断。

### 3. 长按格子标色

**标题：把思路标在盘面上。**

在标色模式下，长按空格，展开环形色盘；滑向一种颜色，松手留下标记，再选同色即可取消。用颜色连接需要比较的位置，让还没有形成答案的思路也能被看见。

| 标注 | 文案 |
| --- | --- |
| 长按入口 | 在标色模式下，从正在观察的空格展开操作。 |
| 环形色盘 | 滑向色块、松手确认，不必离开盘面另找入口。 |
| 颜色标记 | 标出需要对照的位置；再次选择同色可以清除。 |

### 4. 唤出分步辅导

**标题：卡住时，先给一条线索。**

长按顶部绿色进度条，辅导卡从下方展开。先看被标出的范围，试着自己推一步；还需要帮助，再继续查看解释。

| 标注 | 文案 |
| --- | --- |
| 观察范围 | 高亮相关区域，把注意力带到这一步需要检查的位置。 |
| 技法名称 | 标明这一步使用的解题方法。 |
| 先自己想想 | 在进一步解释之前，留出自己判断的机会。 |
| 指导进度 | 分段查看辅导，按自己的理解速度继续。 |
| 返回解题 | 收起卡片，回到盘面亲手完成这一格。 |

### 5. 设置与个人偏好

**标题：按自己的习惯解题。**

对局规则、盘面辅助、导师、声音与触感分别整理。你可以逐项调整，也可以选择更接近纸上解题的方式，把判断留给自己。

| 标注 | 文案 |
| --- | --- |
| 对局规则 | 调整一局的规则与反馈方式。 |
| 盘面辅助 | 选择高亮、候选和手势等辅助偏好。 |
| 导师设置 | 选择合适的辅导方式。 |
| 外观偏好 | 调整主题与盘面外观，让长时间观察更合习惯。 |
| 玩家署名 | 为分享给朋友的题目留下自己的名字。 |
| 底部导航 | 在记录、残局、教程与设置之间切换。 |

### 6. 经典残局

**标题：遇见值得慢慢解的一道题。**

经典名题保留出处、难度与相关背景。你可以先独立尝试，也可以打开分步解法，研究关键一步怎样发生。

| 标注 | 文案 |
| --- | --- |
| 经典名题 | 集中浏览已有的经典题目。 |
| 题目列表 | 选择一道题，打开它的介绍与盘面。 |
| 难度与出处 | 了解题目的挑战程度与来源。 |
| 历史渊源 | 认识题目背后的作者与故事。 |
| 分步解法 | 从题目进入逐步推演的过程。 |

### 7. 分步解法

**标题：把一段解法慢慢看清。**

解法按步骤呈现，盘面随之变化。可以播放，也可以停在某一步，查看当前技法与落子；超出已有技法的步骤会注明「揭晓」。

| 标注 | 文案 |
| --- | --- |
| 题目与评级 | 确认正在研究的题目。 |
| 解法盘面 | 随步骤变化，呈现当时的盘面状态。 |
| 当前步骤 | 说明这一刻正在推进哪一步。 |
| 播放与暂停 | 连续观看，或停下来自己检查。 |
| 步骤进度 | 在已有解法中选择要研究的位置。 |
| 解法说明 | 标明当前技法与落子，超出已有技法的步骤注明「揭晓」。 |

### 8. 记录册与回看

**标题：留下解过的题，也留下走过的路。**

记录按日期留下难度与用时，日志热力图呈现一段时间的解题足迹。保存了完整题面与落子过程的对局，还可以重新回放，看看自己如何走到最后。

**局部图注**

日期、难度、用时，帮助找到某一局；对局回放帮助重新看见当时的判断。

### 9. 保存与分享残局

**标题：一道题，可以留给下次，也可以交给朋友。**

未完成的盘面可以存入残局库，留待下次继续。分享时，为它起个名字，把当前的填写进度一起交给朋友，让交流从同一道题开始。

| 标注 | 文案 |
| --- | --- |
| 残局预览 | 发送前确认盘面与已经填写的数字。 |
| 进度摘要 | 看清这一局已经推进到哪里。 |
| 为残局命名 | 留下一个便于识别、也带着个人意味的名字。 |
| 发送给朋友 | 通过系统分享面板发送，朋友可接着解或先保存。 |
| 返回对局 | 收起分享界面，继续当前这一局。 |

### 使用措辞

- **品牌主张统一用「凡事有解」。** 「留一点安静，给下一步思考」只作双机画面的短文案；不继续叠加多组同级口号。
- **启动 Logo 是脉动与对角光波。** 当前实现不是物理弹跳；后续采集按真实效果呈现。
- **AI 写设计目的，演示标真实方式。** 已有离线与联网辅导分支；当前作品集辅导截图和录屏是离线示例。本轮未验证在线服务，不写「实时 AI 推理」或覆盖全部技法的承诺。
- **进度条是自定义交互。** 不把它写成系统 Liquid Glass 进度组件；玻璃材质的说明对应 iOS 26 的实际按钮，较低版本有回退。
- **主题色与格子标色分开说明。** 两者各有用途，不将两组颜色当作同一套选择器。
- **经典名题与个人残局分开。** 前者用于研究已有题目，后者用于保存、继续和分享自己的对局。
- **回放以数据完整为前提。** 不写所有旧记录都能回放；不承诺格子颜色随残局永久保存。
- **版本以画面来源为准。** 当前统一截图与录屏来自原生维护构建 `1.2 (28)`；不将其等同于公开商店版本的全套画面。
