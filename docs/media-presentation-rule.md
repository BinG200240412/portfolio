# 媒体展示规范

矩形图片与视频采用四角向内的圆切口：圆心位于媒体展示边界的四个顶点，各切去四分之一圆。切口真实透明，露出底层页面。

- 默认四角半径一致，随展示尺寸调整，保持轻巧。
- 可放大图片悬停、键盘选中或触屏按压时，仅左上与右下的圆切口连续加深，右上与左下保持默认半径；四角全程保持四分之一圆弧。离开后反向还原，单击直接放大，无须寻找角落箭头。
- 选中态的两处切口要有明显的尺度变化：半径按默认值的 3.4 倍计算，同时不超过展示短边的 34% 与 96px；默认态保持轻巧，宽扁缩略图按短边收敛。
- 使用约 420ms 的圆弧半径变化，让对角加深与还原清晰可见；减少动态模式下直接切换。保持原有键盘操作、焦点返回和弹窗期间暂停背景吸附。
- 展示层处理切口，不修改素材源文件。图片详情显示完整原图，保证角落的图示、文字和细节可检查。
- 放大图片是作品页上的一层。打开后沿用左上角返回箭头，第一次返回只关闭图片、恢复原页面和焦点；再次返回才离开当前页面。图片详情不再显示第二个叉号关闭按钮；键盘 Escape 仍可关闭。首页内嵌作品与独立打开的作品页遵循同一规则。
- 页内视频只作静音预览或展示封面，不提供进度、音量、重播等参数控件；悬停、键盘选中与触屏按压时，左上和右下的圆切口按图片同一尺度加深。点击后打开独立原生播放器，才提供播放、声音、进度和全屏操作，完整画面不裁角。
- About me 的原照及圆点装饰画框、Skills 版画档案中的整张纸面不切角，保留完整四角；仍可点击和用键盘放大。画框用真正的灰色圆点构成装饰，不用连续线条模拟点阵。
- 原始透明图标、点阵角色、Canvas 场景、真实手机硬件有自身轮廓；矩形展窗裁展窗，不剪坏内部对象。保留原始矢量资产。
- 素材只供站内展示和预览，移除原图、SVG、视频、PDF、ZIP 和源文件下载入口；图库用按钮与预览数据打开站内弹窗，不链接原文件。图片与弹窗限制保存菜单和拖出，播放器追加 `nodownload`，保留播放、声音、进度与全屏。共享限制同样覆盖动态 SVG、Canvas 和弹窗中的媒体，不受切角豁免影响。公开网页仍不能彻底阻止保存、截图或录屏。

共享实现为 `assets/media-corners.css` 与 `assets/media-corners.js`，所有页面统一引用。已有图库继续使用自己的放大入口；没有入口的普通作品图片由共享层补齐。项目导航链接仍执行导航。

常规保存入口限制使用 `assets/media-view-only.css` 与 `assets/media-view-only.js`，每个独立页面和首页均需加载；正文复制、作品导航与 App Store 链接正常保留。

视频双态使用 `assets/video-detail.css/js`，在切角脚本前加载。它保留原页内 video，详情使用独立播放器，避免样式和自动播放策略互相干扰。打开时设置 `html.video-detail-open` 并在 document 派发 `portfolio:video-detail`（`detail: {open, source}`）；由专页管理自动预览的视频标记 `data-video-preview-managed="true"`，在此事件中重算可见性并暂停/恢复。关闭时先归还有效进度，再解除状态、恢复原有预览策略与焦点；页面/宿主隐藏时停止详情播放。切角豁免和详情播放器都继续受素材保存限制约束。

有明确“操作过程 → 定格 → 界面拆解”时序的手机演示由专页管理，视频标记 `data-video-detail-ignore`，保留原手机硬件与终帧放大入口。它不由共享脚本包装成第二个播放器；仍受保存限制，离屏、页面隐藏及媒体弹窗打开时暂停。数独的实现为 `assets/sudoku-demo-player.js`。
