# 关于我 · 履历与项目预览

四类履历改为连续纵向排列，取消中等宽度的两列两排。桌面每类的标题在左、履历在右；手机为单列，保留原文字尺度、日期、照片与点阵画框，不添加分隔横线。

八个项目在原标题之后、职责之前展开小图，最大 320×184 CSS px；一次只展开一项。图像位于文档流中，会推开后续文字。鼠标离开或键盘焦点离开后收起；触屏仍可直接点项目进入作品页。小图本身也沿用原有作品导航。图片仅在列表进入视口时预热，或单项悬停时优先读取，首页首屏不请求这些文件。

素材与原文件 SHA256 记录在 `assets/about-previews/sources.json`。衍生图等比缩小、无裁切或重绘：数独和 Arright 使用真实原生截图，狗 GO 用项目封面，良渚用 Marble 结果，千里江山用实物装置，Skills 用原始矢量海报，漂移之屋用现有方案图。茶弦记使用空间体验构想封面，不将其描述为完成的空间系统。八张共约 182 KB。

同时移除七组已有图片流的普通 hover 暂停：茶弦记课程、Skills 版画和图标带、狗 GO 技术与现场图、数独 UI 墙与迭代时间轴。原速度、材料和操作暂停条件保持。共享吸附脚本补一次首帧重建，保证 defer 执行时先建立页面类，再生成正确的侧边导航。

浏览器验证中读取实际 `:hover` 状态为 true，并比较连续帧的 transform 或 scrollLeft：七组均持续位移。茶弦记主动暂停有效，Skills 版画点击打开详情，关闭后鼠标留在原图上可继续移动。About 项目预览以鼠标停留和键盘聚焦触发，展开后图高不超过 184px，后续条目同步下移；点击小图使用作品导航并将返回焦点交回项目标题。
