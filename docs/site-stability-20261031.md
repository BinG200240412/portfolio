# 连续浏览、资源失败与媒体开销修复

本轮从 6e0c5a3 开始，处理浏览到中途的卡顿与整块空白。保留原有排版、原生点阵、悬停时持续运动、真实素材和原图详情。

## 已确认的问题

- 首页退出案例仅隐藏 iframe，旧页面的媒体、未结束的请求和部分动画仍有运行条件。现在真正退出时移除旧文档；先保存 About 返回位置和 Practice 路径，媒体打开时先归还父层返回按钮。
- Skills 图标库以 43 项 Promise.all 全成功为显示条件；任一失败即整库不显示。现在最多 4 并发，成功分批显示，单项 10 秒超时、单独重试；筛选与已开详情保留。隐藏、离屏和离场中止排队，恢复后继续。
- 狗 GO 交互分析也以四项全成功才播放揭示动画，一项失败会隐藏其他已载入 SVG。改为逐图加载与揭示、逐图重试，保留原路径与生长动画。
- 数独界面墙在 decode 失败时留下 opacity:0。现在保留可见画面，语言版本失败可回退到上一可用原生截图。
- 图片切角每次 resize 对全体媒体重建 52 点路径并重复写样式。现在同半径复用，按帧先测量、后写入，尺寸不变不重复写。
- Skills 深层锚点可能在空图库尚未取得高度时被原生吸附拉回封面，图库无法进入可见范围。现在先将对应章节定位，读者开始操作后不再抢定位。
