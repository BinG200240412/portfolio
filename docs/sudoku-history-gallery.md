# 双语历史录屏与界面展示墙

2026-10-27。按作者反馈，视觉系统之后不再重复讲解功能，将原「它如何被使用」替换为「界面一览」。前面的视觉系统负责说明设计选择，后面的真实界面墙展示整款产品的范围与统一气质。

## 历史录屏

价值观左侧保留同一官方 iPhone 外框，内部展示 App 原生 About 中的历史部分。中文与英文分别录制，保留完整历史标题、引言、五个历史节点和结尾；随网页语言切换影片及开头帧，不在网页中改写视频内文字。

可见时静音循环，离屏、页面隐藏、打开媒体弹窗或所在 iframe 未激活时暂停。减少动态偏好下显示开头帧；点击仍可进入共享播放器。页内不显示进度和音量控件，弹窗使用原生播放、进度、音量与全屏控件。素材来源见 `assets/works/sudoku/history/SOURCES.md`。

## 界面一览

桌面四条纵向界面带，相邻列反向缓慢滑动，轻微倾斜但不改变截图内部透视。手机端合为两列，保留全部独立画面。截图仍以官方 iPhone 外框展示，点击进入原有大图窗口。

墙内有十三种真实界面，每种都有中英文图源与标签，跟随 `portfolio:language` 切换。新增二十二张原生截图，另复用四张既有中文截图。循环副本不可获得键盘焦点，鼠标通过可见副本代理到同一原图；关闭放大或键盘进入卡片时，将对应原卡片定位到可见区域。悬停、聚焦、手动暂停、离屏和弹窗等暂停原因分别处理，鼠标移开不会覆盖用户选择的暂停状态。

「界面一览」保留 `#experience` 章节与 `#sudoku-gallery` 旧链接；原过程录屏、拆解脚本、示意操作和长说明从本页撤下，文件作为制作档案保留。成果与迭代对照继续跟在展示墙之后。

实现为 `sudoku-history-film.js`、`sudoku-ui-wall.css/js` 和页面中的真实素材引用；共享视频播放器、图片放大与素材展示限制继续使用原有实现。没有添加下载入口或模拟不存在的产品状态。

验收包含历史影片的双语切换、循环和共享播放器；展示墙的四列移动、暂停与继续、可见副本放大、关闭后焦点可见、十三张原卡片在两列布局中完整保留，以及 320、390、768、1440 像素视口。视觉系统和成果段落与此次修改前逐字一致。图片来源与录屏原始证据保存在 `artifacts/sudoku-history-gallery-20261027/`，网页行为截图另存其 `qa/` 子目录，不随网站发布。
