# 全站连续浏览与三张原生封面

基于 a32725d，继续检查良渚 AI 3D、千里江山、狗GO 体验场所，并排查全站共用的退出清理与内容可见条件。没有改案例叙事、素材或已确认的构图。

## 已确认的问题与处理

- **良渚 AI 3D**：24,006 点预览之后升级 480,000 点时，同步解析长循环、重复编译着色器与重设画布造成额外工作。解析改成约 5ms 预算的小段；离开封面暂停完整读取/解析，回来继续，已有视角保留。完整升级复用着色器，尺寸未变不重设画布。请求有限时与原有重试，真正退出时释放 GPU、观察器和点数据；BFCache 保留恢复。
- **千里江山**：封面脚本排在翻译之后，每帧重复计算被前景遮住的层与空白天空。同一组灯珠优先启动，跳过空白和遮挡采样，合并每帧三角函数，尺寸不变不重建。浏览器进一步实测仍有持续长任务，因此新增 WebGL 批绘：原灯珠/光晕贴图进入图集，原坐标、颜色、透明度与绘制顺序不变，一次批绘替代逐珠调用，并保留 2D 回退。吸附边界零面积相交不再继续绘图。
- **狗GO 体验场所**：只有进入可见范围才请求 4,372 B 地图数据。416 点原数据现在随绘图脚本生成，进入之前已准备好。进入时 16 组交错灯珠自身闪亮，380ms 动画加最大 165ms 错峰，随后原地图全部稳定显示。引导线同步快速生长。减少动态/强制颜色直接显示地图；离屏、隐藏与离场暂停或清理，筛选和四组游客组合保留。
- **全站父节点观察器**：仅移除 iframe 未显式断开附着在父文档上的观察器。新增受管生命周期；父页先归还媒体返回按钮，再 dispose 捕获的旧文档，最后移除。23 个已有组件接入，另由地图、千里江山和 AI3D 管理各自清理。BFCache 暂时断开父观察并恢复，混用同一观察器监听父子文档的实例已拆分。
- **数独双机**：三张图片全成功才显示整组。改成每层独立可见、近视口开始限时、单独重试；一层错误不隐藏已经完成的两层。

## 验证证据与界限

- 真实 24,006/480,000 点坐标、颜色与随机 seed 新旧逐字节相同。Node 解析桩完整数据最长单段约 78ms 改为约 5.6ms、13 次让步；这是解析测试，不能当浏览器 FPS。
- 千里江山 42 组尺寸/主题/时刻/涟漪绘制记录一致；alpha 差不超过浮点误差。1512px 地形采样 175,500→55,137，减少约 68.6%。纯 CPU 桩耗时减少不等于公网帧率提升。
- 后续真实浏览器在相同 390×844、英文白色环境下，2D 绘图近 30 帧中位约 46.1ms，批绘约 7.7ms；2560×1440 批绘中位约 14.9ms。这是本机浏览器的绘图主线程计时，不等于真机测试或端到端 FPS。冻结同一时刻、1512×982 的黑白截图对照，山水区域平均 RGB 绝对差分别约 0.71/0.68（0–255）；同一贴图保留，渲染采样存在微小差异。adapter 的批次编码、扩容、上下文恢复、2D 回退及生命周期另行验证。
- 地图源 SHA、416 点坐标/半径/分类、4×16 游客组合与原 JSON 一致；生成器 --check 通过。浏览器在进入前 nativePlace=ready / 416 cells，进入后正常连续可见时约 564ms 稳定为 ready。若中途暂停，DOM 的 wall-clock 记录会包含暂停时长。
- 30 次模拟进入/退出后父观察登记为零；一次性清理、重复登记、BFCache、真实 ambient 主题恢复、旧文档捕获和媒体归还顺序均通过。没有把登记计数当成实际堆内存下降比例。
- 实际浏览器对数独单张截图首次返回 503：另外两层 ready/visible，失败层隐藏；只重试失败源，随后恢复三层 ready。
- 本地从总站连续打开八个一级入口与两项练习，退出后旧 iframe 为零；图片返回先关图片，再回练习，最后回总站。AI3D 可旋转并显示完整点云，离屏后帧计数停止，三组原生工作流正常显示；千里江山首绘与键盘涟漪正常。

首次传输仍由实际网络和托管服务决定。本轮验证针对已复现的主线程工作、晚发请求、整组空白条件和退出资源清理，不以静态资源大小或截图代替全部交互的性能证明。

## 2K 持续运行的补充修复

批绘之后的正式站检查仍测到无悬停、无涟漪时采样/打包占主线程约 38.4ms，而 GPU 提交仅约 0.1ms。因此继续抽出同一纯内核，用 Blob Worker 采样并打包；主线程首绘后仅上传/批绘。每次只有一个任务，排队只保留最新输入，ArrayBuffer 真实转移并复用；尺寸、主题与减少动态变化拒绝过期结果。离屏/隐藏不继续投递，真正退出终止 Worker 并释放 Blob URL；Worker/显卡不可用时沿用同步回退。

本机浏览器 2560×1440 的内嵌案例实测超过 6,000 帧，主线程批绘近 30 帧中位约 0.1ms、后台计算约 4–5ms；启动后未再持续增长长任务。该数字只覆盖绘图主线程，不是整个页面的渲染或网络耗时。真实 Worker transfer 测试 5 项、独立并发边界 7 项通过；9 组逐珠对照点数/图案/顺序相同，GPU Float32 格式的几何差不超过 0.000114 CSS px、透明度差不超过 2.98e-8。冻结时刻与原图比较，山水区域平均 RGB 绝对差约 0.94/255（含未冻结的轻微背景粒子）。

同时补上延迟离场的清理捕获：进入下一项练习前旧 iframe 可能已被 replaceChildren 移除，必须在排队之前捕获旧文档的绑定 dispose 函数，再按媒体归还→旧文档清理→移除的顺序执行。三个真实函数测试场景均通过，不影响新文档。
