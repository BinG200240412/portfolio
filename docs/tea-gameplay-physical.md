## 茶筅与 M5

固件 `m5/chaxian_whisk/chaxian_whisk.ino` 使用 M5StickC Plus 的陀螺仪，读取转动强度，经平滑/阈值转换为虚拟绕圈速度和坐标，再通过 USB 串口输出。游戏存在 `window.ChazhanSensor` 输入接口。网页没有宣称其为蓝牙连接、三维位置跟踪或茶沫品质识别。

新增 Canvas 点阵示意：真实竹茶筅、柄端可拆卸套筒、M5StickC Plus、屏幕粒子响应。可切换装入/拆开，用滑杆模拟动作强度。模块按窄竹柄之外的扩大套筒绘制，属于装配示意而非已经测量验证的结构图。

本轮未连接 M5 实物；现有本地材料不足以独立验收实体装配与完整转发。作者提供的实体联动经历不由本次示意替代，后续另补真实现场录制。原固件与游戏源码的实际链路可查，不将示意动画伪装成硬件直播。

## 四关合一与击拂定向演示（2026-10-30）

`#play` 是唯一游戏主章节，旧的 `#wake / #grind / #fencha / #whisk / #rhythm` 留作章内兼容锚点。前后切换、点击两侧预览、组件内方向键和横向触摸手势共用同一选择状态。桌面分析从中央向左右展开，窄屏排到画面下方；不拦截整页滚轮、触摸或键盘滚动。

前三关仍使用已有 iPad 自动演示录屏和真实试玩。第四关默认通过 `chazhan.html?guide` 加载网页专用 `whisk-guide.js`，直接使用原游戏的点阵、茶沫、短/长/红波构造、盏沿覆盖判定、粒子爆发与 Web Audio 声部；场景生成改为定向教学时序，明确标注自动操作，不记录成绩、不授予徽章。未带 `?guide` 的原游戏直接返回，不改判定、关卡或真实试玩。桌面 iPad 工程不改。

讲解包含：同一动作的实体与虚拟两端反馈、短波接奏、长波多次切奏、红波停手与误触对照、白沫与七汤、声音与节奏。基本拍速来自原型 `BPM=80`；七汤增加密度、半拍、长波/红波比例及鼓点/拨弦层次。七个按钮映射原 `SOUPS` 与 `drawFoam`，不是将演示进度当成实物茶沫传感测量。最后可观看原游戏的汤花成纹渲染，无通关奖励写入。

图内竹筅/茶盏是动作示意，与原游戏的虚拟击拂共用角度。实体端的目标是实际完成一盏茶，画面端同步演奏与显影；此处不冒充 M5 实时连接或实体成沫录像。声音必须由观众主动开启；离屏、切走击拂、打开弹窗或隐藏页面时卸载演示 iframe，停下声音与渲染。减少动态偏好下只渲染选中的静帧。


### 舞台倒角与连续滚轮（2026-10-30）

根据作者本次明确要求，游戏舞台豁免共享内凹圆切口，使用凸出的连续圆角、细金属倒角和轻薄侧面阴影。四张卡片沿同一弧形轨迹运动，临界阻尼弹簧连续落位；拖动跟手、松手投射惯性，横向触控板及 Shift 滚轮支持滚动，普通纵向滚轮保持网页阅读。真实视频与击拂演示随所属卡片移动，过渡期间暂停渲染，落位后恢复；减少动态偏好直接切换。图内竹筅缩短柄与头部、扩大筅穗宽度，不改封面或实体装配图。
