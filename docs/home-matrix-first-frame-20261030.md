# 首页点阵与标题一起呈现

原版点阵虽然已经 defer，仍排在 i18n-main、i18n、theme、pixel-loader 之后。defer 保证执行顺序，因此语言或主题脚本较慢时，标题可见而绘图还无法启动。

将原来的八个 matrix 脚本按相同顺序、完整源文件字节合并为一个首页入口，优先预加载，并放在非绘图脚本之前执行。生成物 98,636 B，原始源码、点间距、密度、动画与原生交互保持不变；不使用截图或静态替身。

原文件是维护入口。`python3 scripts/build-home-matrix.py` 重建，`--check` 检查缺失或过期；生成文件记录各源文件 SHA256，模块以明确分号隔断。`python3 scripts/sync-shared-assets.py` 会先重建再更新 HTML 中的内容版本，preload 与 script 始终使用相同 URL。
