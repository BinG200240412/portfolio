# 数独作品页：四部分内容框架

2026-10-25 · 本轮实现后的工作底稿。后续按四部分逐项调整。

主线：**为什么做 → 希望它是什么样的软件 → 它如何被使用 → 最终做到了什么。**

## 一、为什么做

页面 `#intent`：保留「学会推理，分享喜悦。」与现有设计说明，延续首屏盘面回正、缩小停靠和随文退出的动画。

这一部分承接创作动机、价值观、数独历史与独立推理的教育意义。历史界面的具体展开仍留待后续调整，本轮保留现有第一部分。

## 二、希望它是什么样的软件

页面 `#character`：调性、设计原则、字体与外观统一说明。

- 从清楚、安静与纸笔的温度出发，解释具体视觉选择。
- 字标 Fraunces；中文源云明体，英文 EB Garamond。
- 题目数字 EB Garamond；填写与候选笔记 Mynerve。页面展示真实字体样张，中文样张在英文模式下仍保留中文字形。
- 纸白与墨色承载主体信息，六种信号色与自定义选择用于偏好调整。

本部分讲选择理由；具体的设置、外观切换操作归入第三部分。

## 三、它如何被使用

页面 `#experience`：按真实体验组织界面和交互。

- 图库：主棋盘、分步辅导、设置、经典残局、分享残局；切换时同步解释每个界面的用途，保留真实截图和官方 iPhone 外框。
- 解题操作 `#interaction`：保留可试用九宫格、填数、候选笔记与撤销。网页为操作示意。
- 理解与辅导 `#coaching`：保留离线隐性唯一三层解读，说明线索、停顿与继续推理。
- 一局之外：保存与恢复、日志与回看、残局与分享。日志功能有源码依据，目前不放不存在的日志截图。

主要内容自然向下阅读，删除旧的固定章节目录。四个大板块保留全站要求的原生版面吸附，长内容可继续滚动读完。

## 四、最终做到了什么

页面 `#outcome`：用早期界面与当前维护版本对照，说明数字字形、填写颜色与层级的调整；收束设计、交互与原生 iOS 实现，并连接真实 App Store 入口。

旧图仅作明确标注的迭代对照。当前五张绿色截图来自维护构建，来源与字体授权见 `assets/works/sudoku/SOURCES.md`。
