# 数独作品页：表达结构与素材清单

2026-10-24 · 五章网页初稿已用现有材料展开。正文、目录与交互示意先供作者审阅；后续按本清单补真实原稿、录屏和版本对照，不放空图框。

目标：让访客看到作者如何把一局数独设计成清楚、安静、能持续推理的体验。每段讲一个判断，再用一个具体操作或版本变化证明它。

开场沿用动态点阵、sudoku.、凡事有解，以及 App Store / 产品官网两个入口。正文建议用以下五个方面组织，避免只罗列功能或连续堆手机截图。

## 当前网页初稿

- 01 设计目标：短引言、观察→判断→落子的关系，以及本人设计开发署名。
- 02 盘面设计：数字、候选、信号色三个层级；五张绿色原生界面可切换与放大。
- 03 操作体验：可试用九宫格，支持填入5、候选笔记、撤销与重置。这是网页交互示意，后续用同题原生录屏补充。
- 04 分步辅导：以现有一张真实辅导画面，分别解读线索、高亮与提问。三个层次不是完整辅导录像。
- 05 产品迭代：网页原型→原生iOS→上架的路径，及经典残局/分享界面的回看入口；尚未编造具体迭代时间、反馈或成果数字。

目前“为什么做”的文案是设计目标初稿，请作者根据真实创作动机修改。

## 页面节奏

点阵开场 → 创作动机 → 盘面视觉秩序 → 操作与反馈 → 分步辅导 → 产品闭环与迭代。

- 每段优先一张主图或一段短录屏，配一句判断和少量解释。
- 主视觉、正文和界面展示共用连续背景；保留阅读留白，不以整块不透明版面遮住点阵。
- 视觉系统正文讲的是本款极简产品的字体、间距、绿色和反馈。另一个美式报刊视觉项目独立呈现。
- 成果写可验证的事实；不预先编造用户研究、增长数据、获奖、定价或AI效果。

## 第一批素材：先补这四组就能继续

1. 创作动机、本人职责、制作时间，短句即可。
2. 最能体现操作与推理的两段录屏：填数/笔记/撤销；完整的一次分步辅导。
3. 主棋盘设计源文件、字体/色彩/间距说明，加一版早期方案。
4. 一次真实的产品迭代：改之前、改之后、为什么改。
