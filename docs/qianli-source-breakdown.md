# 千里江山：横版原稿到网页

来源：Figma `zhuMFpEI4lq8hiP0RRZ2hf` / `2025作品集`。桌面文件夹的 16 张横版对应以下原生画面。原稿未修改；网页采用独立文字、原始图片填充和矢量图层，而非整页截图。

| 原稿画面 | 网页内容 / 锚点 |
| --- | --- |
| 14 设计前言、15 两种形式 | 设计动机与两条路线 `#overview` |
| 16 文化与交互切入、17 元素剖析 | 提取与转译、原画色彩 `#elements` |
| 18 音光造型 | 山形、切割图与层次 `#music` |
| 19 音调、颜色与情感 | 10 位测试者的原始矢量研究图 `#colour-study` |
| 20 音频采样、21 LED 映射 | 音频处理链路、原稿参数与映射片段 `#audio` |
| 22 木板制作与赋色 | 六张制作原图 `#wood` |
| 23 灯带装配 | 六张装配原图 `#led` |
| 24 音光呈现 | 实物照片与原装置视频 `#music-result` |
| 25 点阵造型 | 触摸路线 `#touch`、六步独立图示 `#matrix` |
| 26 触摸光纤回路 | 原生网页回路图与实物细节 `#circuit` |
| 27 打孔与编组 | 六张制作原图 `#fibre` |
| 28 传感器装配 | 灯箱与反光结构 `#light-boxes`、传感器装配 `#sensors` |
| 29 光纤呈现 | 实物照片与原装置视频 `#touch-result` |

素材与节点映射见 `assets/works/qianli/case/source-manifest.json`。照片转换为 WebP；点阵与轮廓保留 SVG；调性研究另有英文文字衍生版本。两段视频由原稿二维码指向的原装置视频导出，转为本地 MP4，保留原音频。

网页沿用共享 `page-snap.js` 对 `qianli.html` 的登记，每个内容 section 独立吸附，长内容自然增长。图片弹窗打开时暂停背景滚动及吸附。视频手动播放，离开画面或切换标签页时暂停。封面继续使用既有流动山水与光珠涟漪实现。

原稿代码以资料片段展示，未宣称完成 Arduino 编译或实体装置复测。
