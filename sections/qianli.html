设计前言

突破时空限制、激活传统文化的现代生命，是当今文化传播的重要命题。

本设计以《千里江山图》为原型，通过新技术、新材料的运用——分解重组、提取颜色、新"国布"等手法，赋予它新的生命，让这幅近千年的青绿山水，焕发出传统文化新的眼界与表达。

音光互动

画面随音乐变换光亮——声音驱动色彩，让画"听得见"。

人机光互动

通过手触摸激发光点——触碰驱动光亮，让画"摸得到"。

切入点

从五个维度，把一幅静态的画，重新理解为可被激活的空间。

色彩与材质

原画以石青、石绿等矿物颜料为主，以 LED 与光纤还原其青绿色调。

空间与结构

原画"平远、高远、深远"结合，以灯条与点阵还原山的堆叠与虚实。

技法与形态

笔法的层次，转译为光的层次——不同区域，附着不同色彩。

互动与表达

原画是静态观看，装置让"千里江山图"回应你的声音与触碰，活起来。

元素剖析

第一步解构画面的空间感——它主要由山的堆叠与虚实变化构成；第二步把山切割为独立个体，依颜色与大小重新排列；第三步在每个个体后加以灯带，与外部环境绑定。

音光互动

把山形抽象为二维线条、依颜色分布布置灯条；再用麦克风采集声音、经 FFT 频域分析，由 FastLED 把音乐的节奏与频率映射成色彩与亮度——让《千里江山图》随音乐呼吸。

造型设计

第一步把山形抽象为二维线条，调整前后空间关系与虚实；第二步划分山的颜色分布，在适当位置设计灯光结构，于不同区域附着色彩。

原理解析

先做了一场"调性 — 颜色 — 情感"的匹配研究：让测试者把不同调性对应到颜色与情绪（抗争 / 纯洁 / 深刻 / 轻盈 / 温暖 / 辉煌……），作为音乐驱动灯光的映射依据。

用 MAX4466 电容麦克风采集音频信号，经 FFT 频域分析取出峰值频率与振幅；再由 FastLED 把峰值频率映射为色相、振幅映射为亮度，实现基于音乐节奏的灯光映射。

// 峰值频率 → 色相，振幅 → 亮度 int hue = map(peakIndex, 0, SAMPLES/2, 0, 255); CRGB color = CHSV(hue, 255, 255); for (i = 0; i < LED_COUNT; i++) leds[i] = color; int brightness = map(maxAmplitude, 0, 0.2, 0, 255); FastLED.setBrightness(brightness); FastLED.show();
呈现效果

最终呈现为一幅随音乐而波动的长卷《千里江山图》——光在矿物色之间流动，画面随节奏明灭起伏。

人机光互动

一座立体山形模型，表面布满光纤点与触摸传感器：触碰某个区域，以传感器为中心的光点便依次点亮，错开层次——让观者用指尖唤醒一片山。

造型设计

提取山形样本做颜色分析 → 划分颜色区域 → 抽象成点阵（一个点 = 一个光纤点）→ 光源分区、点阵后布置触摸传感器 → 手触摸点亮以传感器为中心的光点 → 光点延时、错开层次依次点亮。

运行逻辑

把连接在前方区域的光纤打组、捆在相应灯珠前，以一颗灯珠控制一块区域的光纤；再用 Arduino 单片机的数字信号控制 LED 灯组与光纤颜色，达到多层次、多色彩的效果。触摸传感器预先布置在装置表面，触碰即点亮对应区域。

呈现效果

暗室之中，蓝色光纤点亮成山——被触碰的区域率先发光，光点以涟漪般的层次向外扩散，一座可被唤醒的"千里江山"。
