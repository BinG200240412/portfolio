查看版画 Skill ↗

  1. 参考转绘

    锁定构图与两色印刷语言。

  2. 审核画面

    检查墨量、格线与文字残留。

  3. 修补与定色

    校对真实文字与数字，统一墨色。

  4. 去除底色

    保留排线与细小飞白。

  5. 描摹为 SVG

    把纹理与轮廓留在矢量路径里。

  6. 入库验证

    回渲、检查，再放进实际界面。

正在整理 SVG 档案…

不止相似，
逐项校对。

我在 Figma 排好界面后，发现只让 AI 看图，布局和间距仍会偏；反复描述细调也很慢。
于是我写 Skill，让 CLI 读节点、按元素与分组测量位置和间距、理解功能，再回到原生实现和模拟器检查偏差。

查看界面还原 Skill ↗

  1. 按分组测量

    边界、对齐与间距一起核对。

  2. 先导出原始资产

    保留 SVG 与真实字体。

  3. 还原原生界面

    在 SwiftUI 中保留既有行为。

  4. 构建与截图比对

    模拟器校验，逐项修正偏差。

留一点
手绘的不规则。

保留每一个轮廓的轻微歪扭，让图形自然融入页面。
点击图标，放大查看原始矢量轮廓。

查看面型图标 Skill ↗

  1. 确定主体

    用少量块面表达核心含义。

  2. 形成手绘轮廓

    保留弯曲、参差与不对称。

  3. 描摹与精确填色

    #41403D，透明底，真实路径。

  4. 缩小检查与交付

    检查孔洞、边缘与小尺寸辨识。

为什么做

我不想让每次版画转绘、界面还原和图标描摹都从零开始，于是把反复做的判断整理成可复用的工作流。

从中学到

我学会把审美手感翻译成可检查的步骤，同时保留最后由人决定构图、边缘与尺度的权利。
