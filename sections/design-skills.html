01 / VISUAL ARCHIVEsudoku-image-style

把印刷的痕迹
留下来。

铜版画的排线，老报纸的缺墨、飞白与毛边。
将散落在海报、每日挑战和 App 里的图像，收进同一面 SVG 展示墙。

查看版画 Skill ↗
  1. 01 / TRANSLATE

    参考转绘

    锁定构图与两色印刷语言。

  2. 02 / AUDIT

    审核画面

    检查墨量、格线与文字残留。

  3. 03 / REPAIR

    修补与定色

    校对真实文字与数字，统一墨色。

  4. 04 / CUTOUT

    去除底色

    保留排线与细小飞白。

  5. 05 / VECTORIZE

    描摹为 SVG

    把纹理与轮廓留在矢量路径里。

  6. 06 / VERIFY

    入库验证

    回渲、检查，再放进实际界面。

02 / INTERFACE CALIBRATIONUI—COPY—CODE—FIGMA

不止相似，
逐项校对。

先理解 Figma 分组，再量距离。
导出原始资产、还原字体与布局，最后回到截图，逐项比对。

查看界面还原 Skill ↗
  1. 01 / MEASURE

    按分组测量

    边界、对齐与间距一起核对。

  2. 02 / EXPORT

    先导出原始资产

    保留 SVG 与真实字体。

  3. 03 / BUILD

    还原原生界面

    在 SwiftUI 中保留既有行为。

  4. 04 / COMPARE

    构建与截图比对

    模拟器校验，逐项修正偏差。

03 / HANDCUT LIBRARYhandcut-solid-icons

留一点
手绘的不规则。

保留每一个轮廓的轻微歪扭，让图形自然融入页面。
点击图标细看，也可以选几枚，带走原始 SVG。

查看面型图标 Skill ↗
  1. 01 / DEFINE

    确定主体

    用少量块面表达核心含义。

  2. 02 / SHAPE

    形成手绘轮廓

    保留弯曲、参差与不对称。

  3. 03 / VECTORIZE

    描摹与精确填色

    #41403D，透明底，真实路径。

  4. 04 / CHECK

    缩小检查与交付

    检查孔洞、边缘与小尺寸辨识。
