# Portfolio sticker sources

`kiss-woman.svg` reuses the author’s existing `FigmaPaidWinkWoman` vector asset from the Sudoku iOS project. It contains the curly-haired woman blowing a kiss, her hand and a small heart. No poster layout or text is included.

`assets/matrix-project-stickers.js` samples its native transparent contour into 64 × 76 whole LED points. The source SVG remains intact and editable; only its sampled point representation is used by the homepage.
